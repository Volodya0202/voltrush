## ✨ Возможности

- **🚀 Быстрый старт**: Автоматическая загрузка клиента и java.
- **👤 Система ников**: Валидация, генератор и сохранение.
- **📦 Менеджер модов**: Включайте и выключайте моды в один клик.
- **📊 Мониторинг**: Онлайн серверов в реальном времени.
- **🎵 Радио**: Слушайте музыку прямо в лаунчере.
- **🌍 Мультиязычность**: Русский, English и другие языки.
- **🌍 Играйте на любых серверах**: Доступны любые сервера, лицензия/пиратка.

## 🛠 Установка и Запуск

### Windows
1. Скачайте `.exe` файл.
2. Запустите его (Windows может спросить разрешение — это нормально для нового приложения).
3. Играйте!

### Linux
1. Скачайте `.tar.gz`.
2. Распакуйте архив.
3. Запустите исполняемый файл [VoltRush](cci:1://file:///D:/a/HyPrism-main/Backend/AppService.cs:5928:4-5999:5).

### macOS
1. Скачайте `.dmg`.
2. Перетащите в Applications.
3. Запустите.
